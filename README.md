# ⏰ タスクアラーム

今日やることを「時間帯＋内容」で登録して、時間になったらデスクトップ通知と音で知らせるタスク管理アプリ。
単一HTMLファイル・ライブラリ依存なし・データはブラウザのlocalStorageに保存されます。

**公開URL**: https://apps.l-mine.com/task-alarm-app/

## できること

- 時間帯（開始〜終了。終了は空でもOK）と内容でタスクを登録
- **▶開始 / ⏸中断 / ▶継続 / ✓完了** で状態を切り替え
- 完了しなかったタスクは**翌日に自動で持ち越し**（何日持ち越したかバッジ表示）
- 「毎日くり返す」にすると、完了しても翌日また出てくる**ずっと残るタスク**になる
- 開始時刻にデスクトップ通知＋アラーム音（予告通知・終了通知・スヌーズあり）
- アラーム音は3種類（ベル／ピピッ／チャイム）＋音量・鳴らす回数を設定可能
- 履歴タブで過去の日の実績を確認
- JSONでバックアップの書き出し／読み込み

## 使い方

1. https://apps.l-mine.com/task-alarm-app/ を開く
2. 上部の黄色いバーの「通知を許可する」をクリックして、ブラウザの許可ダイアログで「許可」
3. 「音をテスト」で音量を確認（設定タブで調整できます）

ローカルで動かす場合は `起動.bat` をダブルクリック（`http://localhost:8977/` で開きます）。
`index.html` を直接ダブルクリックしても動きますが、ブラウザによっては `file://` だと通知がブロックされるため、
通知を使うならサーバー経由（上記URL または 起動.bat）がおすすめです。

## 注意点

- アラームは**このタブを開いている間だけ**動きます（最小化・裏に回すのはOK、閉じるとNG）
- ブラウザの仕様上、ページを開いたあと**最初に1回どこかをクリック**すると音が鳴るようになります
- データはそのブラウザの中だけに保存されます（別PC・別ブラウザとは共有されません）。
  移したいときは設定タブの「バックアップ書き出し」→ 移行先で「読み込み」

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（HTML/CSS/JSすべて） |
| `起動.bat` | ローカルサーバー（python http.server）で開くランチャー |
